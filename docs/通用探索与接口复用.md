# 通用探索与接口复用

登录后本人账号权限内的查询与操作均可按需对接，预置 Q/W 只是快捷入口。AI 从实际页面和请求形成契约，保存后按明确业务条件复用。登录页只负责本人登录授权，完成即可关闭。

1. `connector_status` 恢复并核实当前调用端的本人账号。
2. `start_discovery` 从聚水潭首页或可访问的普通页面开始独立探索。
3. `inspect_discovery` 查看文字、筛选元素、链接、iframe、公开脚本和截获请求。公开脚本仅作分析材料，凭据不会作为工具结果提供。
4. `interact_discovery` 使用最新元素编号填写条件、点击或选择。未知 XHR、表单等请求在发送前截获；页面点击不获得业务写入授权。
5. `propose_read_interface` 将实际观察的请求整理为只读契约，声明用途、依据、可变条件、成功规则和数据结构。连接器校验来源、动作语义及参数边界；写入或用途不明的请求不能执行。
6. `validate_read_interface` 在当前已授权连接的读取范围内试查一次。只有成功规则和响应结构都满足时才可保存；无需返回登录页逐接口批准。
7. `search_capabilities` 查已保存接口，`call_saved_interface` 按明确声明的条件复用。业务条件不清楚时，由 AI 在当前对话询问本人。

模板固定端点、方法和调度字段。公司、员工、Cookie、CSRF 和令牌由当前连接器提供，不接受模型指定或作为可变条件替换。保存模板按调用端、当前身份与会话绑定隔离，并在本机加密保存。

一次调用只执行一页请求。完整性、总数和是否有下一页须根据返回字段与页面约定核实，不能自行补造总数。接口或响应变化、账号变化或会话绑定失效时，需重新核对。

## 通用写入

1. 在独立探索页填写并触发相应页面动作，请求发送前被截获，不会因探索就真实提交。
2. `propose_write_interface` 保存真实捕获请求、可变参数、响应成功规则、单一操作对象、已验证只读回查接口、前置条件和预期字段。
3. `preview_write_interface` 从当前 ERP 读取同一对象的数据，检查前置条件，生成包含实际请求、变更前数据、预期结果及执行边界的预览。
4. 显示完整预览后 `request_operation_confirmation` 由本人核对确认。本机只向本人浏览器交付一次性确认能力；远程返回需员工网页登录的普通确认网址。已有可信系统确认可复用原签名通道。
5. `execute_confirmed_operation` 提交前再读数据，变化则重新预览；账本占用后只提交一次，按响应业务成功条件和真实回查预期字段判断结果。
6. `operation_status` 查询持久结果；超时、请求中断、回查不符均保留未知记录。设置 `recheck=true` 可只读回查并在证实原预期已生效后更新原记录，不重新提交。重新提案或重新预览不能绕过未知或正在执行的记录；成功后真实状态变化时，允许重新预览、重新确认后执行新的业务事件。

写契约的最小示例（编号和业务字段须来自实际页面，不能照抄示例调用）：

```json
{
  "target": {
    "request_path": "/body/document_id",
    "read_interface_id": "当前账号已验证的精确查询编号",
    "read_parameters": {"id": "/body/document_id"},
    "read_target_path": "/id"
  },
  "preconditions": [{"path": "/status", "equals": "draft"}],
  "expected": [{"path": "/note", "request_path": "/body/note"}]
}
```

创建可用已知唯一业务键绑定精确查询，并声明 `target.allow_missing_before=true`；删除可声明 `target.allow_missing_after=true`，同时以根路径预期明确回查为空。默认执行前后都核对同一对象，每项可变写字段须声明对应预期回查。工程测试包含创建、修改和删除，不将业务类型收缩为备注维护。

单一对象与一次请求是当前通用执行边界，不是假定 ERP 已提供整批事务。跨对象、多请求的整批保证须另取证，不支持部分成功的批次不能自动拆开循环执行。支持 JSON、表单和固定解码的回调写请求及查询响应；复杂隐藏状态、无法重建的认证字段、其他编码及风控按实际接口补充适配。这些是协议核对要求，不是业务类型白名单。

前置数据校验会明确说明已验证和未验证内容；读取当前数据、比对声明条件不等于聚水潭试算接口已经验收。某操作依赖额外试算或业务预校验时，须先核实该接口并补齐契约，不以模型推断替代。
