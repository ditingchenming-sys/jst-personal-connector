# 通用探索与接口复用

预置查询只作快捷入口。AI 可按当前账号权限探索未预置页面，核对只读请求后试查，保存供后续更换业务条件复用。登录页只负责登录授权，完成后即可关闭。

1. `connector_status` 恢复并核实当前调用端的本人账号。
2. `start_discovery` 从聚水潭首页或可访问的普通页面开始独立探索。
3. `inspect_discovery` 查看文字、筛选元素、链接、iframe、公开脚本和截获请求。公开脚本仅作分析材料，凭据不会作为工具结果提供。
4. `interact_discovery` 使用最新元素编号填写条件、点击或选择。未知 XHR、表单等请求在发送前截获；页面点击不获得业务写入授权。
5. `propose_read_interface` 将实际观察的请求整理为只读契约，声明用途、依据、可变条件、成功规则和数据结构。连接器校验来源、动作语义及参数边界；写入或用途不明的请求不能执行。
6. `validate_read_interface` 在当前已授权连接的读取范围内试查一次。只有成功规则和响应结构都满足时才可保存；无需返回登录页逐接口批准。
7. `search_capabilities` 查已保存接口，`call_saved_interface` 按明确声明的条件复用。业务条件不清楚时，由 AI 在当前对话询问本人。

模板固定端点、方法和调度字段。公司、员工、Cookie、CSRF 和令牌由当前连接器提供，不接受模型指定或作为可变条件替换。保存模板按调用端、当前身份与会话绑定隔离，并在本机加密保存。

一次调用只执行一页请求。完整性、总数和是否有下一页须根据返回字段与页面约定核实，不能自行补造总数。接口或响应变化、账号变化或会话绑定失效时，需重新核对。

当前支持可核验的 JSON 查询；老式回调、复杂隐藏状态、其他编码和未适配风控可能需要额外适配。未知请求无法核实时明确停止，不通过任意 HTTP 或 JavaScript 绕过检查。当前全部真实制单、修改、审核和付款仍关闭。
