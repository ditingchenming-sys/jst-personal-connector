# 聚水潭个人连接器

一个聚水潭连接器，默认使用 ERP，按需兼容分销。为 AI 和业务系统提供本人登录、页面探索、查询和业务操作；不以预置 Q/W 清单限定业务范围。支持 Windows 本机和 Linux 多员工远程部署，对接方只需配置一套 MCP、一个服务地址和本人的调用授权。

统一入口：[GitHub 仓库](https://github.com/ditingchenming-sys/jst-personal-connector)；安装包入口：[最新 Release](https://github.com/ditingchenming-sys/jst-personal-connector/releases/latest)。

把本仓库链接交给 AI，并告诉它：

> 请读取 https://github.com/ditingchenming-sys/jst-personal-connector 中的《AI接入说明.md》，在当前环境安装聚水潭个人连接器并配置 MCP，保留我的其他配置，再引导我本人登录。

AI 客户端通过 MCP stdio 使用工具。本机模式调用本机组件；远程模式通过 stdio 适配器连接 HTTPS 员工服务，不在员工电脑保存聚水潭 Cookie。仅接受远程 MCP URL 的客户端仍需单独适配；HTTPS 员工服务地址不是 Streamable HTTP MCP 地址。

## 当前能力

当前版本 **0.6.1**，提供 **18 个 MCP 工具**。

| 能力 | 说明 |
|---|---|
| 本人登录 | 连接器登录页内填账号密码；只在聚水潭要求时由本人收取、填写短信验证码 |
| 登录恢复 | 本机加密保存登录态；不同 AI 调用端独立登录，主动退出账号清除对应资料 |
| 基础查询 | 预置查询目录，具体可用状态和参数通过 `search_capabilities` 获取 |
| 按需对接 | AI 查看页面、观察请求，形成查询或写入契约并保存；预置接口不是功能上限 |
| 条件调整 | 保存模板后，可更换模板明确声明的业务条件并复用 |
| 系统嵌入 | 提供 SDK、签名任务及员工本地执行通道；目标业务系统仍需独立配对和联调 |
| 业务写入 | 实际截获请求 → 真实数据预览 → 本人或可信系统确认 → 提交 → 结果回查；防重复、会话绑定和未知结果记录共用 |
| 多员工远程授权 | 承接可信平台已验证的钉钉等员工身份，无须另建员工密码；独立部署保留密码模式；每人每调用端隔离 |
| 按需兼容分销 | 本人ERP已连接时，分销首次调用自动接续并复用，无需再点接续或输入分销密码；仍是同一个连接器 |

通用写入已提供单对象单请求的契约执行路径，支持 JSON、表单和已解码的固定回调请求；它不证明聚水潭跨单据、多步骤事务。复杂批次须先核实提交边界，不能伪造整批原子性。预置 W 快捷方式未适配时应使用通用探索，不能据此判断该业务被禁止。具体接口仍需来源、当前真实数据、业务校验及回查依据；复杂隐藏状态和未适配风控按实际协议补齐。

登录页只负责本人登录授权、验证码、连接状态和退出，完成后即可关闭。后续查询和条件交互在 AI 或业务系统中完成。

工作台已经通过钉钉等方式登录时，由工作台可信后端接入[平台身份授权协议](INSTALL.md#平台已登录的身份接入)，员工继续平台授权后直接连接本人聚水潭。平台登录与聚水潭登录仍分别验证；不能只传员工ID、复用其他员工令牌或把钉钉Cookie当聚水潭Cookie。未配置平台身份接入的独立部署继续使用原有员工密码方式。升级包不会自动取得任意工作台的登录身份，对接方须配置可信后端及授权入口。

ERP 和分销是同一个连接器里的两个业务板块。业务人员平时只连接本人ERP；确有分销任务时，同一套工具指定 `area="drp"`，连接器自动通过已验证的本人ERP接续分销，成功后直接执行业务请求并复用有效会话。无需业务人员再切登录板块、点接续或输入分销密码。普通ERP使用不会加载分销。内部仍分别保存会话、契约和执行账本，不把ERP Cookie直接发送到分销域；一个远程进程和一个HTTPS域名即可承载两者。

工作台、市场和 AI 配置只显示一个“聚水潭个人连接器”；分销作为兼容能力，不新增第二张卡片或第二组 MCP 工具。旧版独立分销部署的数据和绑定保留，迁移时不得按重名员工自动合并；见[统一接入与旧版本兼容](INSTALL.md#聚水潭分销平台)。

独立操作确认页只确认当前预览；已有可信系统确认无需重复打开。AI 持有的调用令牌不能自行批准写入。本版工程验证使用隔离数据与受控服务，不代表全部真实业务接口已验收，也不会为发布而创建真实单据。

## 维护与更新

更新仓库说明后，AI 再次读取链接即可获取新说明。**本地已安装的程序不会随仓库修改自动升级**；发布新版本后按 [安装说明](INSTALL.md) 更新并重启相关 MCP。保留本机运行目录和原有密钥，更新不需要把登录资料交给维护者。

开发环境：Python 3.11+。使用 `uv sync --extra dev` 安装依赖，`uv run pytest -q` 执行离线和受控回环测试，`uv build --wheel` 构建 wheel。测试不使用真实 ERP 账号。
